Install in Seconds

Get started with PRD Creator MCP in just one command

$ npx -y prd-creator-mcp
# or install globally
$ npm install -g prd-creator-mcp

Add to Claude Desktop 

{
  "mcpServers": {
    "prd-creator": {
      "command": "npx",
      "args": ["-y", "prd-creator-mcp"]
    }
  }
}
